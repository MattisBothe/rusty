# 📜 Code of Conduct

## Unser Versprechen

Ich als Maintainer verpflichten mich, die Teilnahme an diesem Projekt zu einer belästigungsfreien Erfahrung für alle zu machen – unabhängig von Körpergröße, Behinderung, Ethnizität, Geschlechtsidentität, Erfahrungsstand, Aussehen, Herkunft, Religion oder sexueller Identität.

---

## Unsere Standards

**Positives Verhalten umfasst:**

- Respektvoller und freundlicher Umgang miteinander
- Konstruktives Feedback geben und annehmen
- Verantwortung übernehmen und aus Fehlern lernen
- Das Wohl der Community im Blick behalten

**Inakzeptables Verhalten umfasst:**

- Beleidigungen, Trolling oder persönliche Angriffe
- Öffentliches oder privates Harassment
- Veröffentlichung privater Informationen anderer ohne Erlaubnis
- Spam, Off-Topic Issues oder absichtlich schlechte Pull Requests

---

## Contributions

Wer zum Projekt beitragen möchte:

1. **Fork** das Repository
2. Erstelle einen **Feature Branch** (`git checkout -b feature/mein-feature`)
3. Halte dich an den bestehenden Code-Stil
4. Beschreibe in deinem **Pull Request** klar was du geändert hast und warum
5. Öffne bei Fragen oder Ideen zuerst ein **Issue** bevor du direkt einen PR erstellst

> Pull Requests die Token, API Keys oder andere Secrets enthalten werden sofort geschlossen.

---

## Melden von Problemen

Falls du inakzeptables Verhalten beobachtest oder Sicherheitsprobleme findest, melde dich direkt bei Mattis.

---

## Durchsetzung

Ich behalte sich mir Recht vor, Beiträge abzulehnen oder Personen bei Verstößen gegen diesen Code of Conduct vom Projekt auszuschließen.

---

## Grundlage

Dieser Code of Conduct basiert auf dem [Contributor Covenant](https://www.contributor-covenant.org), Version 2.1.
